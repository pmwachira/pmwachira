### 🧭 About

I design and maintain production data pipelines — orchestration, ELT, and analytics engineering — with a focus on correctness and observability over cleverness. Recent work spans:

- **Orchestration** — Airflow DAGs with dynamic task mapping, deferrable sensors, and asset-based cross-DAG triggering
- **ELT** — API-to-warehouse ingestion (Stripe, payment processors) landing to GCS and BigQuery
- **Analytics engineering** — dbt models on BigQuery, incremental strategies, data quality checks
- **Cloud** — Google Cloud Platform (BigQuery, GCS, Cloud Composer/Astro)
